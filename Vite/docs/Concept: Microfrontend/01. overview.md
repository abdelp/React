# Concept: Microfrontends

**What is a microfrontend?**

A microfrontend is a microservice that exists withing a browers.

## Comparison to Microservices

## Concrete Technical Definition

In the context of single-spa a microfrontend is often an in-browser JavaScript module.

## Types of Microfrontends

1. **single-spa application:** Microfrontends that render components for a set of specific routes.
2. **single-spa parcesl:** Microfrontends that render components without controlling routes.
3. **utility modules:** Microfrontends that export shared components without rendering components.
