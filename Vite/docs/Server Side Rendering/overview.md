# Server Side Rendering

## Intro to SSR

**In a single page application, what pages does the server generate?**

In a single page application, the server only generates the very first page that the user requests, leaving all subsequent pages to be rendered by the browser.

## Implementation Overview

**What's the ultimate goal of server-side rendering?**

The ultimate goal of server-side rendering is to generate an HTTP response that the browser will display to the user while javascript is hydrating.
